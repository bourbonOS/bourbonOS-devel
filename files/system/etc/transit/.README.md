Hello! Transit, a background security service, has found a security risk.
Your full home directory is on the "base layer."
This is **not good**, as it **exposes** your data in the situation that an attacker has **full, unencrypted access to your disk.**
This is usually the result of **rebasing** to this image.
You can either fix this issue by opening a terminal and running `baseos exec /usr/libexec/ostools/fix-homedir` (recommended), or delete this README file and move on. (not recommended)
